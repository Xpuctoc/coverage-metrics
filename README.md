Code base for Master's Qualification Paper in HSE

Files:

- `metrics.py` contains completeness and uniformity estimator
- `utils.py` -- utils for main experiments
- `main_experiments.ipynb` -- experiments including proxy tests, trained generative models comparison, nulti-anchor distance distribution on datasets, walks in latents paths
- `cfm_mnist.ipynb` -- training and inference of Conditional Flow Matching
- `ddim_inference.ipynb` -- Diffusion model inference
- `ae_dim_reduction.ipynb` -- visual coverage experiment
- `walk_in_hypercube.ipynb` -- idea for walks in latent paths
- `distance_distribution_on_dataset.ipynb` -- idea for distance distribution experiment
